# Gatherly — event invitation platform concept

A standalone, static concept landing page for a flexible event invitation and guest-management product. This is a new project, separate from the christening invitation site.

## Run locally

Open `index.html` in a browser. No build step, package installation, backend, or account is required.

The page includes an interactive dashboard mockup with guest filters and search, a sample-guest form, and a guest invitation page with an account-free RSVP flow. Use **Preview guest invite** to open the invitation or **Share invite** to copy/share its `#invite` link. All displayed guest and event details are fictional. Guest edits and RSVP replies are stored in this browser with `localStorage`; they are not sent to a host or synced across devices.

## Free hosting for a client demo

This project is designed for a zero-cost presentation workflow. The simplest option is GitHub Pages:

1. Create a public GitHub repository and push the project files.
2. In the repo settings, go to Pages.
3. Select the default branch and the root folder (`/`).
4. Save the setting and wait for the Pages URL to be generated.
5. Share the published URL with the client.

This gives you a free, static demo site that is easy to update and present without hosting fees.

## Product caveats

Gatherly is a working brand name for the concept. Product scope, pricing, dates, locations, and sample guest data are placeholders. The guest invitation and RSVP are a client-presentation prototype only; there is no authentication, real invitation delivery, messaging, or shared RSVP backend. It is intentionally a static prototype for early client validation and presentation.
